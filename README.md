# Я / Мы — опросник

Опросник комплексной модели личности: самооценка и оценки других людей об одном человеке. Результат — комплексное число `z = Я + i·Мы`, квадрант, угол от точки баланса и профиль восьми векторов.

Модель: «Фрактальная свёртка восьми векторов системно-векторного психоанализа. Комплексное число личности v3», В. Лещинский, октябрь 2006. На основе школы Виктора Толкачёва.

Рабочий адрес: [https://217.160.139.56/opros/](https://217.160.139.56/opros/)

## Как устроен опрос

Два режима.

- **Я о себе.** В начале вводится свой псевдоним. Он обязателен. После 40 вопросов самооценка сохраняется сама.
- **Я о другом.** Обязательны два псевдонима: того, про кого анкета, и того, кто её заполняет.

Псевдоним — это постоянный id человека. Одинаковый псевдоним (без учёта регистра и лишних пробелов) всегда указывает на одного и того же человека. Все ответы о нём — и своя самооценка, и чужие оценки — собираются в один профиль, чтобы их можно было сравнить.

Шкала ответа: 0 — совсем не про человека, 4 — очень про него.

## Кто видит профиль

Сводный профиль — самооценку и оценки окружающих — видит только тот, кто заполнил «Я о себе» под этим псевдонимом, и только из своего браузера. Остальные участники чужие профили не видят: ни в списке «Мои профили», ни по прямой ссылке. Тот, кто оценивал другого, после отправки видит только свой собственный результат и счётчик оценок.

Идентификация — по cookie `opros_visitor`: при первом заходе сервер выдаёт браузеру случайный токен (срок 10 лет, `HttpOnly`). При сохранении самооценки хэш этого токена записывается в `subjects.owner_hash`, и профиль закрепляется за браузером. Отсюда два следствия:

- заполнить «Я о себе» под уже занятым псевдонимом из другого браузера нельзя — сервер отвечает `403`, нужен другой псевдоним;
- после очистки cookie или с другого устройства доступ к своему профилю теряется. Админ видит все профили через админку.

Для подсказок при вводе псевдонима в режиме «Я о другом» доступен список всех псевдонимов — без содержимого профилей.

## Локальный запуск

```bash
python3 server.py
```

Откроется [http://localhost:8080/](http://localhost:8080/). Другой порт: `python3 server.py 9000`. Свой файл базы: `OPROS_DB=/path/to/base.db python3 server.py`.

## Запуск на хостинге

Nginx (`passion-gateway`) отдаёт `/opros/` на контейнер `opros`, порт `172.21.0.1:8090`.

```bash
cp .env.example .env   # если файла ещё нет: одна строка ADMIN_TOKEN=...
docker compose up -d
```

`.env` в репозиторий не попадает. В нём только пароль админки `ADMIN_TOKEN`. Разрешённый адрес входа задан в `docker-compose.yml`: `vleschinskii@gmail.com`.

После правки `server.py` контейнер нужно перезапустить: `docker restart opros`. `static/index.html` читается с диска при каждом запросе.

## Админка

Страница: [https://217.160.139.56/opros/admin](https://217.160.139.56/opros/admin)

В меню опросника ссылки нет. Вход — почта из списка `ADMIN_EMAILS` и пароль `ADMIN_TOKEN`. После входа видны записи базы и кнопка выгрузки `opros.csv`: id того, кто заполнил, id того, про кого анкета, баллы и все 40 ответов.

## База

Таблица `subjects` — люди: числовой `id`, псевдоним и `owner_hash` — хэш cookie-токена браузера, из которого заполнена самооценка (владелец профиля).

Таблица `responses` — ответы:

- `subject_id` — про кого анкета;
- `author_id` — кто заполнил (для самооценки совпадает с `subject_id`);
- `mode` — `self` или `other`;
- ответы, баллы восьми векторов, Я, Мы и квадрант.

У человека может быть только одна самооценка. Повторное прохождение с тем же псевдонимом спрашивает, перезаписать ли её.

## API

Пути ниже — как их видит сервер. На хостинге перед ними стоит `/opros`.

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/api/health` | Проверка, что сервер жив |
| GET | `/api/subjects` | `subjects` — мои профили (владелец — этот браузер), `names` — все псевдонимы для подсказок |
| GET | `/api/subjects/<псевдоним>` | Самооценка и оценки окружающих. Только владелец или админ, иначе `403` |
| POST | `/api/responses` | Сохранить 40 ответов |
| DELETE | `/api/subjects/<псевдоним>` | Удалить профиль и ответы о нём. Только владелец или админ |
| DELETE | `/api/subjects` | Удалить все профили. Только админ |
| POST | `/api/admin/login` | Вход в админку |
| GET | `/api/admin/data` | Содержимое базы, нужна сессия |
| GET | `/api/admin/export.csv` | CSV, нужна сессия |

Тело `POST /api/responses`:

```json
{
  "mode": "self",
  "subject": "Анна",
  "answers": [0, 1, 2, 3, 4],
  "overwrite": false
}
```

Для режима `other` поле `subject` — псевдоним того, про кого анкета, поле `rater` — псевдоним того, кто заполняет. Оба обязательны. В `answers` ровно 40 целых чисел от 0 до 4. Если самооценка с таким псевдонимом уже есть и принадлежит этому же браузеру, сервер отвечает `409`, пока не передан `"overwrite": true`. Если псевдоним занят из другого браузера — `403`.

В ответе на `self` поле `subject` — полный профиль; на `other` — только `id`, `name`, `has_self`, `others_count`.
